# MasterCrafter

> **Prealfa / Pre-alpha.** Proyecto en desarrollo: habrá cambios y errores. Tu retroalimentación es muy importante. / Work in progress: expect changes and bugs. Your feedback matters.

Herramientas para AION 2 en Windows: medidor de DPS, avisos de eventos, calculadora de crafteo y explorador de base de datos.

- **Descargar / Download:** [MasterCrafter-setup.exe](https://github.com/MasterCrafter-AION2/MasterCrafter-releases/releases/latest/download/MasterCrafter-setup.exe)
- **Página / Website:** https://mastercrafter-aion2.github.io/MasterCrafter-releases/
- **Reportar un error o sugerir / Report or suggest:** [Issues](https://github.com/MasterCrafter-AION2/MasterCrafter-releases/issues/new/choose)

Windows puede mostrar SmartScreen porque la app aún no tiene certificado de editor. Verifica el SHA-256 con `SHA256SUMS.txt` del release.
